Support the project

TRACE is free and MIT licensed and stays that way: no paid features, no account. If it saves you time at the bench, you can chip in for what costs real money.

Support with €5 via Stripe ❤ Buy a coffee on Ko-fi Report a bug

Thank you very much for testing TRACE and sharing your opinion, special thanks for that! If you find a bug, please be sure to report it.

Payments run on those services' own pages; this site stores nothing and sets no cookies.

What it pays for

  • Development — the tools and services it takes to build, test and release TRACE.
  • Code signing — a Windows code-signing certificate removes the SmartScreen warning for everyone, and an Apple Developer Program membership lets the macOS build be signed and notarized instead of shipping as an unsigned experimental build.
  • The website — hosting and upkeep of this page and the downloads.
  • New projects — the next project is coming soon; later ones will be integrated into the TRACE app.

Supporters get the same software as everyone else; progress on these goals is reported in the CHANGELOG.
