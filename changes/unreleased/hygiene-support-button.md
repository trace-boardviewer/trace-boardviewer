- Support button: a small heart in the top bar ("Support TRACE", with a tooltip, in all eight languages) opens the project's support page in the system browser. Once every four minutes (the first one a minute after the window opens) the heart glows softly for 1.5 s; the glow never moves anything, is off under the system's reduced-motion setting and with the Motion setting off, and reads well in both themes. The support notice at start is unchanged. The renderer sends only the fixed id `support` over the existing `trace:open-support-link` channel; the address is a constant of the main process, and every other id is still rejected.
