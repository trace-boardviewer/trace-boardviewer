- Damaged or hostile files no longer freeze the importers. A GenCAD file with thousands of coincident outline segments used to take minutes to open, a KiCad legacy schematic whose library symbol repeats one pin number thousands of times took seconds, and an EAGLE schematic whose device connects one pin to tens of thousands of pads took half a minute; all three are now read in time proportional to their size, with the same result as before.
- A KiCad legacy pin length or page size, an Altium sheet symbol size or an Altium circle radius that is not a finite number or lies beyond the coordinate limit is refused with the usual "coordinate exceeds the limit" error, instead of giving a position or bounds that the schematic viewer cannot fit.
- EAGLE schematics: when a library symbol lists several pins with one name, the first is kept and the others are ignored with a warning, so that pin ids stay unique.
- Altium schematics: the text a diagnostic quotes from the file is cut to a readable length, and a schematic opened under a name without a file part keeps a usable sheet id. A pin list whose last record ends with a delimiter now keeps the 512-field limit of a record.
