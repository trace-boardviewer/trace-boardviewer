- Boards can be opened straight from a ZIP archive (`.zip` in the open dialog, by drag and drop and from the command line): TRACE looks at every file in the archive that has a board extension, opens the one board it holds and takes its companion files (the ASC trio) from the same folder of the archive; the info dialog names the file that was opened. A KiCad project archive with its Gerber layers opens the board. An archive with more than one board (for example a board and its autosave copy) is refused with their names instead of opening one of them, and an archive without a board says so. The archive is unpacked in memory inside the sandboxed board worker; nothing is written to disk.
- Limits: 64 MiB for the archive and 64 MiB unpacked for the board and its companions, 4,096 entries and a bounded expansion ratio; every entry is checked against its size and CRC-32. Encrypted entries, compression methods other than stored and deflate, split archives and damaged archives are refused with a precise message in all eight languages. Notes and the workspace of a board opened from an archive belong to the archive file.
