- Developer tools: `node scripts/qa-performance.cjs --synthetic=100k` (or `all`) measures the production app on generated boards of 10,000 to 1,000,000 pins, so no private board is needed: open to first paint (reading, worker parse and transfer, scene build), pan and zoom frame cost at fit and at 20 px/mm including the GPU raster wait, hover, search keystrokes, selecting the GND net, idle redraws, memory, and a JSON report. The boards come from `node scripts/gen-synthetic-board.cjs`, a seeded GenCAD generator (BGAs, ICs, connectors and passives on both sides, a large GND net, power rails, small signal nets; 1,000,000 pins in 38 MiB, written in a streaming pass). `config/perf-budget.json` holds the budgets of the master plan; the run reports pass or fail per budget and fails only with `--strict`. Each run records how busy the rest of the machine was (processor share before, after and during the run, other node, electron and browser processes, free memory) and labels the report "quiet" or "under load, indicative"; `--wait-quiet=<seconds>` waits for an idle machine first (`npm run bench:baseline`), and a Markdown table file is written next to the JSON report (`node scripts/perf-report.cjs <report.json> [--compare=<earlier.json>]`).
