- KiCad PCB: real boards that were refused now open. KiCad 5 designs that rename their copper layers (top_copper, Dessus, Top_layer, ...) are read by the layer number and type in the file's layer table instead of failing with "unsupported layer", and the import notes say which names were read that way (ten of the thirteen open KiCad 5 demo boards were refused before). A KiCad 9 board whose pad teardrop settings lack an opening parenthesis, which KiCad itself opens, is read instead of being refused as malformed, with a note that counts them.
