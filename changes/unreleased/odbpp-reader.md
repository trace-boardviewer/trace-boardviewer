- ODB++ product models can now be opened: `.tgz`, `.tar.gz`, plain `.tar`, `.tar.Z` and `.zip` archives (also an archive that holds the model as one nested `.tgz`). TRACE shows the components with reference, package, value, position, rotation and side, the pins with their nets, the packages' pads and outlines and the board profile of the board step, in inch or millimetre files alike. When an archive holds several steps (a board, a panel, a coupon) the step with the most components is shown and the import note names the others. The reader is validated with ODB++ files that the open-source kicad-cli wrote from open designs; no file written by an ODB++ vendor's own software has been tested. Copper, drills, mask and silkscreen are not drawn, and other pad shapes than rectangles and circles are drawn as their enclosing rectangle (the import note counts them).
- ODB++ archives are unpacked in memory with hard limits (decompressed size, entry count, file size, path rules): paths that would leave the archive, links and damaged or oversized entries are never used, and every skipped item is named in the import note. Files are still limited to 64 MiB.
