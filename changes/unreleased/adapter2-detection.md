- Board files are now told apart by how certain each reader is about the content, not by the order in which the readers were registered: every reader rates the first 64 KiB of the file, the most certain one reads it, and the next one is tried only when it declines. Files that opened before open the same way. A file whose content fits two formats with certainty (for example a KiCad board that also carries a GenCAD `$HEADER` line) is no longer read by whichever reader happened to come first: it is refused with a message that names both formats, in all eight languages.
- The format filters of the open dialog now list every extension TRACE accepts, each under one family; ODB++ `.tgz` and IPC-2581 `.cvg` files were missing from them.
