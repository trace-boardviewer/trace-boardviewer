- Large boards: every part of the window (board view, inspector, component list, note editor, breadcrumb, selection and cross-probe) now looks parts, pads and nets up in one shared index per board instead of building its own maps or scanning the whole board. On a synthetic board with 250,000 pins the interface spends about half as long blocked while the board opens, and the lookup data it keeps for the board is about 70 % smaller.
- Search and the board-to-schematic comparison now run in a background worker that keeps the open board, so typing in the search field no longer makes the window stutter on very large boards. On the 250,000-pin board, 18 keystrokes over five searches went from 12 to 14 pauses of 50 to 120 ms each to none. Only the answer to the newest query is shown, and if the worker stops unexpectedly the window does the work itself.
