Native Unisoft F2B archives now import component references, pin labels, pin XY,
electrical nets and placed-pin sides. The reader validates counted MFC records,
object references and dictionaries through EOF. Other archive/payload versions
are identified and refused with an export suggestion.

Component bodies and pad sizes are estimated from pins. Tracks, vias, native
outlines, BOM values and annotations are omitted and disclosed during import.
Diagnostics report only content-free framing facts.
